# 作家 Agent 0.1.2

本版把已在本地作家安装的压缩修复同步到源码和 Windows 分发包。保留 SageWrite 采用快照、40 个 MCP 工具及配套运行依赖，不增加问题看板，也不代表写书或出版质量已经验收。

## 压缩行为

摘要设置值作为验收上限，首次生成目标为上限的 85%，超限则从原历史以 70% 目标重试一次。例如上限 10000，首次要求至多 8500，重试至多 7000；两次都超限或无法计数则保留原对话，不截断。比例与固定触发量继续取较早达到者。成功重试时累计两次模型调用用量。

新实例默认比例 30%、固定触发量 50000、摘要验收上限 10000。已有实例的非空设置保留，不强制修改为新默认；例如已有 3000 上限时，生成目标自动按 2550、2100 计算。该上限只针对历史摘要，当前问题、系统指令和工具说明另计。

## 如何安装或升级

- 新安装使用 Setup-0.1.2.exe，包含桌面、原生引擎、Node、MCP 运行依赖和桌面快捷方式。首次自行配置模型；不含账号、书稿或聊天。
- 已安装 0.1.1 使用 0.1.1-to-0.1.2-Upgrade.zip。退出作家并停止它的手机后端，将升级包解压到原程序目录外，运行 Upgrade.cmd，指定原安装目录及外部备份目录，完成后从原入口启动。先备份、核对程序哈希，再更新；模型、原聊天和 workspace 书稿保留。
- 升级包接受原版 0.1.1，以及已核验的本次本地压缩补丁引擎。未知程序修改会停止升级，不盲目覆盖。0.1.0 请先按对应升级包升到 0.1.1，再升级本版。完整安装器拒绝覆盖已有实例。
- 本次不修改公共签名升级中心，不代表所有已安装子机已自动更新。Windows 已安装的本地作家保留现状；本次 GitHub 发布不再重启或重装它。
